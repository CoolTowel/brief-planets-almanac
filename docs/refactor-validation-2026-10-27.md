# Topo 重构验收记录

日期：2026-10-27。实现方案已由用户批准；默认海拔采用用户选定的 0 米。

## 交付

- 正式 CLI 为根目录 `main.py`，提供 `all`、`generate`、`render`。
- `almanac/` 分离不可变 Topo、星表、计算、数据集和绘图；绘图不再决定年份、时区或观测点。
- 固定时区推导经度，日期与平闰年由标准库日期范围处理；UTC+14 保留日期线两侧的正确日期归属。
- 修复两颗恒星负赤纬、月面实际观测者、EOT 参数年份被覆盖、主图和背景年份不一致。
- 每次生成新建可读唯一目录，包含 manifest、配置、星表、数据形状与单位、文件哈希和算法版本；旧数据不自动混用。
- 20 份旧脚本按原目录结构归档到 `legacy/`。用于历史 2027 基准的原始脚本校验值与归档文件一致，Astronomy Engine 源码校验值未改变。

## 保留的边界

- 本轮不扩展极昼极夜排版；数据可记录无事件，缺少合法太阳边界时完整绘图明确拒绝。
- 固定时区代表标准经线上的观测地，不接受独立真实城市经度或夏令时。
- 均时差正负号、夜晚归日、月面几何和图形样式按批准方案保留。
- 回归验证证明重构对已有算法的保持，不等于完成了独立高精度星历的科学认证。
