# 曲线标注与轻量 GUI 验证

本次仅修改绘图标注、显示开关及入口编排；未改动天文计算、TopoContext、星表、数据协议、月面几何或固定引擎。

## 实现

- 思源黑体 Regular 9 pt：行星出、没、上中天与恒星标注按显示空间弧长逐字排布，字符随局部切线旋转；月份竖排并随边框倾斜。
- 渲染器负责实际字体度量和点到像素换算。PNG / PDF 各自重新排字，不固定某个 DPI 的像素坐标。
- 可见段沿用既有夜间掩码，缺失段不跨接。标注避让边框、中央刻度、其他文字，并尽量避开月相；极短或没有空间的曲线段不强行加字。
- GUI 使用标准库 Tkinter 与子进程，复用 `main.py all`；年份、时区、纬度仍由 TopoContext 校验，海拔默认 0 米。
- 恒星开关只影响恒星曲线及文字的显示。CLI 的 `all` / `render` 同样支持 `--no-stars`。
