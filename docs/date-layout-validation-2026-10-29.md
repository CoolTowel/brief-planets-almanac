# 日期排布与横线断开验收

按用户提供的手调参考图完成三项显示修改：日期整体上移 2 pt；仅在与实心满月符号重叠时水平移动日期；月份分界线及顶底横线在日期两侧留出缺口。月份仍固定居中，空心新月不参与日期避让。日期数值、所属夜晚行、月相位置/大小、天文计算和数据文件均未改变。

实现位于 `almanac/date_layout.py`，由 `almanac/render.py` 接入。绘制满月时直接记录已有图元，不再计算天文位置或月相。每个输出渲染器取得这些图元的真实边界，只检查与日期高度相交的图标，依据相邻可用区间解析选择最近的水平位置，不做全图像素扫描或密集候选搜索。日期限制在原有日期栏内。

字体排版框包含上下及左右空白。在日期栏很窄时，这种框会误报重叠，因此日期碰撞使用数字字形的墨迹边界。通过公开字体度量恢复基线，字形轮廓按字体和日期值缓存，最多 31 种日期字符串。横线缺口仍按较宽松的排版框加 1 pt 留白。绘制 PNG/PDF 时分别计算显示坐标，每次重置基础变换，不累积位移。

固定输入：2026、2028 年，UTC+08:00、北纬 40°、海拔 0 米；15×15 英寸，300 dpi。复用先前验证的数据集，不重新生成星历。环境仍为 Python 3.12.13、Matplotlib 3.11.2 及项目锁定依赖。
